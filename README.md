# AmirTomanArbitrage

ربات مانیتورینگ آربیتراژ تتر/تومان بین صرافی‌های ایرانی.

## هدف پروژه

- بررسی قیمت خرید و فروش تتر
- بررسی Order Book
- محاسبه کارمزد معاملات
- محاسبه سود خالص آربیتراژ
- ارسال هشدار از طریق Telegram
- اجرای مداوم و خودکار

## وضعیت پروژه

در حال توسعه

## صرافی‌های اولیه

- Wallex
- BitPin
- Ramzinex

> این پروژه در مرحله اولیه فقط برای مانیتورینگ و ارسال هشدار است و معامله واقعی انجام نمی‌دهد.
